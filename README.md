# WaveChat — دردشة حقيقية بين عدة مستخدمين

تطبيق دردشة عربي باتجاه RTL يعمل عبر الويب، مع تسجيل حساب ودخول، ومحادثات فردية ومجموعات، ورسائل تصل فورًا بين الأجهزة. يعمل محليًا على خادم Node.js بدون أي مكتبات خارجية، ويمكن نشره بشكل دائم ومجاني على Cloudflare Workers، أو باستخدام Docker على أي استضافة.

> النسخة التجريبية القديمة (بدون خادم) محفوظة كما هي في مجلد `demo/` ويمكن فتحها من `/demo/index.html`.

---

## التشغيل السريع

على Windows، من داخل مجلد المشروع:

| الملف | الوظيفة |
| --- | --- |
| `start-server.cmd` | يشغّل الخادم ويفتح `http://localhost:8123` في المتصفح. |
| `start-public.cmd` | يشغّل الخادم + نفق Cloudflare، ويطبع رابطًا عامًا ويعطيك إياه في الحافظة. |
| `stop-wavechat.cmd` | يوقف الخادم والنفق. |
| `serve.ps1` | خادم ثابت للنسخة التجريبية القديمة فقط (اختياري). |

الملفات تجد تلقائيًا:

- Node.js المحمول في `%LOCALAPPDATA%\WaveChat\runtime\...\node.exe`، أو `node` المثبّت في النظام.
- `cloudflared.exe` في `%LOCALAPPDATA%\WaveChat\cloudflared.exe`.

بعد التشغيل افتح:

```text
http://localhost:8123/
```

عند أول زيارة تظهر شاشة «حساب جديد / دخول». أنشئ حسابك ثم شارك الرابط مع من تريد.

### الرابط العام (الإنترنت)

شغّل `start-public.cmd`. سيظهر شيء مثل:

```text
==================================================
 WaveChat is now on the internet:

 https://justin-suspended-prepared-assistance.trycloudflare.com

 The link is copied to your clipboard.
==================================================
```

- الرابط يُنسخ تلقائيًا إلى الحافظة، ويُفتح في المتصفح.
- شارك الرابط مع أصدقائك؛ يستطيع كل واحد إنشاء حسابه والدخول من هاتفه أو حاسبه.
- **الرابط يتغيّر كل مرة** تعيد فيها تشغيل النفق (لأنه نفق سريع مجاني من Cloudflare).
- الخادم والنفق يبقيان يعملان في الخلفية بعد إغلاق نافذة التشغيل. لإيقافهما استخدم `stop-wavechat.cmd`.
- يمكن دائمًا معرفة الرابط الحالي من داخل التطبيق: **الإعدادات ← رابط الدردشة** يعرض `location.origin` مع زر نسخ.

> **مهم:** نفق Cloudflare السريع يجعل التطبيق حقيقيًا ومتاحًا على الإنترنت، لكنه يبقى مرتبطًا بهذا الجهاز. إذا أُغلق الكمبيوتر أو انقطع الإنترنت يتوقف الرابط. للحصول على رابط ثابت ودائم اتبع قسم **النشر الدائم** أدناه.

### النشر الدائم (رابط ثابت لا يعتمد على جهازك)

التطبيق جاهز للنشر كصورة Docker، والبيانات تُحفظ في مجلد `/data` (ملف `db.json`). الملفات المضافة لهذا الغرض:

| الملف | الوظيفة |
| --- | --- |
| `Dockerfile` | صورة Node.js خفيفة تشغّل الخادم على المنفذ 8123. |
| `render.yaml` | إعداد جاهز للنشر على Render مع قرص دائم. |
| `/api/health` | فحص صحة الخادم تستخدمه منصات الاستضافة. |

كل الخيارات تحتاج حسابًا مجانيًا على المنصة (وقد تحتاج بطاقة للتحقق). لا يمكن إنشاء استضافة دائمة anonymously.

#### الخيار 1: Cloudflare Workers (مجاني بالكامل، بدون بطاقة)

هذا هو الخادم الفعلي في مجلد `worker/`، مكتوب ليعمل على Cloudflare Workers + Durable Object واحد مع WebSocket وSQLite. لا يحتاج جهازك بعد النشر.

```powershell
cd worker
npm install
npm run build
npx wrangler login
npm run deploy
```

بعد `wrangler login` اضغط **Allow** في المتصفح. سيطبع `npm run deploy` رابطًا دائمًا مثل:

```text
https://wavechat.<اسمك>.workers.dev
```

هذا الرابط لا يتغير ولا يتوقف عند إغلاق الكمبيوتر. التفاصيل الكاملة في `worker/README.md`.

> ملاحظة: كلمات المرور في نسخة Cloudflare تُشفَّر بـ PBKDF2 (وليس scrypt)، поэтому قاعدة بيانات Cloudflare تبدأ فارغة. الحسابات القديمة في `db.json` المحلي تبقى كما هي على خادم Node.

#### الخيار 2: Render (الأسهل، قرص دائم)

1. ارفع مجلد المشروع إلى مستودع GitHub (يمكن أن يكون خاصًا).
2. سجّل في <https://render.com> ثم **New ← Blueprint** واختر المستودع.
3. سيتعرّف Render على `render.yaml` وينشئ خدمة ويب وقرصًا بحجم 1GB على `/data`.
4. بعد النشر ستحصل على رابط ثابت مثل `https://wavechat.onrender.com`.

> الأقراص الدائمة في Render تتطلب خطة مدفوعة (Starter، حوالي 7$ شهريًا). الخطة المجانية تنام بعد فترة خمول وتفقد الملفات عند إعادة النشر.

#### الخيار 3: Fly.io (رخيص، قرص دائم)

```powershell
fly launch --no-deploy --name wavechat-<اسم-فريد> --region fra
fly volumes create wavechat_data --size 1 --region fra
```

أضف إلى `fly.toml` الناتج:

```toml
[env]
  WAVECHAT_DATA = "/data"

[mounts]
  source = "wavechat_data"
  destination = "/data"
```

ثم:

```powershell
fly deploy
```

#### الخيار 4: خادم VPS خاص

على الخادم (مع Docker):

```bash
docker build -t wavechat .
docker run -d --name wavechat \
  --restart unless-stopped \
  -p 8123:8123 \
  -v wavechat-data:/data \
  wavechat
```

ثم ضع Caddy أو Nginx أمام المنفذ 8123 لشهادة HTTPS ونطاقك الخاص. هذا هو الخيار الوحيد الذي يعطيك تحكمًا كاملًا ونطاقًا ثابتًا.

#### بعد النشر الدائم

- انسخ `db.json` من القرص الدائم بانتظام (أو استخدم لقطة القرص من لوحة المنصة).
- لا تضع كلمات مرور حساسة: التطبيق مصمم لمجموعة أصدقاء/عائلة.
- إن أردت نطاقًا خاصًا، أضفه من لوحة المنصة ووجّه سجل `CNAME` إليه.

## الحسابات وتسجيل الدخول

- **الاسم الظاهر**: الاسم الذي يظهر للأصدقاء (مثال: أحمد محمد).
- **اسم المستخدم**: من 3 إلى 30 حرفًا، بدون مسافات. يسمح بالحروف العربية والإنجليزية والأرقام والرموز `.` و`_` و`-`.
- **البريد الإلكتروني**: يجب أن يكون صحيحًا وغير مستخدم من قبل.
- **كلمة المرور**: 6 أحرف على الأقل.
- الدخول لاحقًا يكون **باسم المستخدم أو البريد الإلكتروني** مع كلمة المرور.
- يمكن تغيير الاسم واسم المستخدم وكلمة المرور من **الإعدادات**.
- تُحفظ الجلسة في المتصفح لمدة 30 يومًا، ويمكن تسجيل الخروج من الشريط الجانبي أو من الإعدادات.

كلمات المرور لا تُخزَّن كنص صريح: تُجزَّأ باستخدام `scrypt` مع ملح عشوائي لكل مستخدم.

## الميزات

- محادثات فردية (DM) ومجموعات.
- إنشاء مجموعة باختيار أكثر من مستخدم، وإضافة أعضاء لاحقًا.
- رسائل فورية بين جميع الأجهزة عبر **Server-Sent Events (SSE)**، دون تحديث الصفحة.
- مؤشرات «متصل الآن»، وآخر ظهور، و«يكتب…».
- علامات تسليم وقراءة (✓ / ✓✓) وتحديث فوري عند قراءة الطرف الآخر.
- عدّاد رسائل غير مقروءة في القائمة وفي عنوان الصفحة.
- بحث في المحادثات، وبحث عن المستخدمين عند بدء محادثة جديدة.
- تحميل الرسائل الأقدم عند التمرير للأعلى.
- منتقي إيموجي، وإرسال بـ `Enter` وسطر جديد بـ `Shift + Enter`.
- مظهر داكن وفاتح (محفوظ محليًا).
- واجهة متجاوبة تعمل على الجوال: قائمة محادثات كاملة، ثم شاشة محادثة مع زر رجوع.
- بدون أي مكتبات خارجية أو خطوة بناء.

## البيانات والنسخ الاحتياطي

كل شيء محفوظ في ملف JSON واحد:

```text
%LOCALAPPDATA%\WaveChat\data\db.json
```

يحتوي على المستخدمين (مع كلمات المرور المجزأة)، والمحادثات، والرسائل، وحالات القراءة، ورموز الجلسات.

- **نسخة احتياطية**: أوقف الخادم ثم انسخ `db.json` إلى مكان آمن.
- **الاستعادة**: أوقف الخادم، ضع النسخة مكان الملف، ثم شغّل الخادم.
- **البدء من جديد**: أوقف الخادم (`stop-wavechat.cmd` أو أغلق نافذة الخادم)، احذف `db.json`، ثم شغّل الخادم. سيبدأ بقاعدة فارغة وتظهر شاشة التسجيل.

بعد حذف قاعدة البيانات تصبح رموز الجلسات القديمة غير صالحة، ويظهر للمستخدمين «انتهت الجلسة». هذا طبيعي.

لتغيير مكان التخزين أو المنفذ:

```powershell
$env:WAVECHAT_PORT = 9000
$env:WAVECHAT_DATA = "D:\wavechat-data"
node server/server.js
```

## التشغيل اليدوي (بدون ملفات cmd)

من داخل مجلد المشروع:

```powershell
# الخادم فقط
& "$env:LOCALAPPDATA\WaveChat\runtime\node-v26.13.0-win-x64\node.exe" server/server.js

# أو إن كان Node مثبتًا في النظام
node server/server.js
```

ثم في نافذة أخرى:

```powershell
# نفق عام
& "$env:LOCALAPPDATA\WaveChat\cloudflared.exe" tunnel --url http://localhost:8123 --no-autoupdate
```

ابحث في مخرجات `cloudflared` عن سطر يحتوي:

```text
https://xxxx-xxxx-xxxx.trycloudflare.com
```

هذا هو رابط المشاركة. الخادم يستمع افتراضيًا على `0.0.0.0:8123`، لذا يعمل محليًا وعلى شبكة Wi-Fi أيضًا.

## التشغيل على الشبكة المحلية (بدون إنترنت)

1. شغّل `start-server.cmd`.
2. اعرف عنوان IP للكمبيوتر، مثل `192.168.1.52`، من `ipconfig`.
3. من الهاتف على نفس شبكة Wi-Fi افتح:

```text
http://192.168.1.52:8123/
```

إذا لم يُفتح، اسمح بالمنفذ في جدار الحماية من PowerShell كمسؤول:

```powershell
New-NetFirewallRule -DisplayName "WaveChat 8123" -Direction Inbound -Protocol TCP -LocalPort 8123 -Action Allow
```

## النسخة التجريبية القديمة

مجلد `demo/` يحتوي نسخة العرض الأصلية كما كانت (HTML/CSS/JS فقط، وبيانات محلية في المتصفح، ومحاكاة للمكالمات والحالات). يمكن الوصول إليها من:

```text
http://localhost:8123/demo/index.html
```

أو فتح `demo/index.html` مباشرة. لتشغيل خادم ثابت مستقل للنسخة التجريبية استخدم:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8124
```

النسخة التجريبية لا تتصل بالخادم الحقيقي، وبياناتها منفصلة.

## تطبيق أندرويد (APK)

مجلد `android/` يبني تطبيق أندرويد حقيقيًا (WebView) يفتح WaveChat كتطبيق مستقل بأيقونة على الشاشة، مع شاشة لإدخال عنوان الخادم وتغييره لاحقًا من **الإعدادات ← خادم التطبيق**.

```powershell
powershell -ExecutionPolicy Bypass -File android\setup-sdk.ps1
powershell -ExecutionPolicy Bypass -File android\build.ps1
```

الناتج: `android\WaveChat.apk` (موقّع محليًا، جاهز للتثبيت المباشر).

- يُنسخ الملف تلقائيًا إلى جذر المشروع، ويصبح متاحًا للتحميل من شاشة الدخول على `/WaveChat.apk`.
- عند أول تشغيل يُطلب عنوان الخادم، ويكون معبأ بالرابط الحالي.
- عند فشل الاتصال تظهر شاشة خطأ فيها زر لتغيير العنوان دون إعادة تثبيت.
- التطبيق واجهة فقط: إن كان الخادم يعمل على هذا الكمبيوتر فسيتوقف عند إغلاقه. انشر الخادم دائمًا أولًا (قسم **النشر الدائم**).
- احتفظ بـ `android\wavechat.keystore` لإصدار تحديثات لاحقة.

التفاصيل الكاملة في `android/README.md`.

```text
├─ android/                تطبيق أندرويد (WebView) وسكربتات البناء

│  ├─ src/worker.js         نقطة الدخول والملفات الثابتة
│  ├─ src/chat-do.js        الدردشة والمصادقة وWebSocket
│  ├─ build-public.mjs      تجهيز الملفات المنشورة
│  ├─ wrangler.jsonc        إعداد النشر

├─ start-public.cmd        تشغيل + رابط إنترنت
├─ stop-wavechat.cmd       إيقاف الخادم والنفق
├─ start-wavechat.ps1      منطق التشغيل المشترك
├─ serve.ps1               خادم النسخة التجريبية (اختياري)
└─ README.md
```

- الخادم: Node.js فقط (`http`, `fs`, `crypto`)، بدون `npm install`.
- التخزين: JSON مع كتابة ذرية (ملف مؤقت ثم إعادة تسمية).
- المصادقة: رموز عشوائية 32 بايت، صلاحية 30 يومًا، وكلمات مرور بـ `scrypt`.
- التحديثات الفورية: SSE على `/api/events?token=...` (لأن `EventSource` لا يدعم ترويسات الطلب).
- الواجهة: HTML/CSS/JS عادي، بدون أطر عمل.

### واجهات API المختصرة

| المسار | الوظيفة |
| --- | --- |
| `POST /api/register` | إنشاء حساب |
| `POST /api/login` | دخول باسم المستخدم أو البريد |
| `POST /api/logout` | إنهاء الجلسة الحالية |
| `GET /api/bootstrap` | بيانات المستخدم والمحادثات والمستخدمين |
| `GET /api/users` | دليل المستخدمين |
| `PATCH /api/me` | تعديل الملف الشخصي أو كلمة المرور |
| `POST /api/conversations` | إنشاء محادثة فردية أو مجموعة |
| `GET/POST /api/conversations/:id/messages` | جلب/إرسال الرسائل |
| `POST /api/conversations/:id/read` | تعليم كمقروء |
| `POST /api/conversations/:id/typing` | مؤشر الكتابة |
| `GET /api/events` | بث SSE للأحداث الحية |
| `GET /api/health` | فحص صحة الخادم (بدون مصادقة) |

## ملاحظات أمان وحدود

- الرابط العام من Cloudflare Quick Tunnel **عام**: أي شخص يملك الرابط يمكنه محاولة إنشاء حساب. شاركه فقط مع من تثق بهم.
- لا يوجد تحقق من البريد الإلكتروني أو استعادة كلمة مرور. مناسب للاستخدام بين الأصدقاء والعائلة، وليس لخدمة إنتاج عامة.
- البيانات على القرص غير مشفرة (عدا كلمات المرور المجزأة). لا تستخدم كلمات مرور حساسة.
- الاتصال عبر نفق Cloudflare مشفّر بـ HTTPS. الاتصال المحلي عبر `http://192.168.x.x` غير مشفّر.
- النفق السريع مجاني وقد ينقطع أو يتغيّر رابطه. لإنتاج حقيقي استخدم خادمًا دائمًا (VPS) مع نطاق وHTTPS، وقاعدة بيانات مناسبة، ونسخًا احتياطية.
- لا توجد رسائل وسائط (صور/ملفات) في هذه النسخة؛ الرسائل نصية فقط.
- لا توجد مكالمات صوتية/فيديو حقيقية في نسخة الدردشة الحقيقية؛ تلك موجودة كمحاكاة في `demo/` فقط.

## استكشاف الأخطاء

**المنفذ 8123 مستخدم**  
شغّل `stop-wavechat.cmd`، أو غيّر المنفذ:

```powershell
$env:WAVECHAT_PORT = 9000
```

ثم شغّل الخادم يدويًا، وافتح `http://localhost:9000`.

**«Node.js was not found»**  
ثبّت Node.js، أو ضع نسخة محمولة تحت `%LOCALAPPDATA%\WaveChat\runtime` بحيث يوجد `node.exe` داخل أحد مجلداتها.

**«cloudflared.exe was not found»**  
نزّله من <https://github.com/cloudflare/cloudflared/releases/latest> وضعه في:

```text
%LOCALAPPDATA%\WaveChat\cloudflared.exe
```

**الرابط العام لا يفتح**  
تأكد أن الخادم يعمل محليًا أولًا (`http://localhost:8123`)، ثم أعد تشغيل `start-public.cmd`. راجع آخر أسطر السجل:

```text
%LOCALAPPDATA%\WaveChat\logs\tunnel.log
```

**«انتهت الجلسة» بعد حذف قاعدة البيانات**  
طبيعي: سجّل الدخول من جديد أو أنشئ حسابًا.

**لا تصل الرسائل فورًا**  
تحقق من مؤشر الاتصال أسفل القائمة: يجب أن يقول «متصل». إن قال «جارٍ الاتصال…» فأعد تحميل الصفحة. بعض الشبكات المؤسسية تحجب SSE.
